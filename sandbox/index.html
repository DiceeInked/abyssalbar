FORCE-FIELD DISTANCES
Set the interaction range for each dot.
Each dot starts with radius 1 cm and an inner/outer range of 2–5 cm. There is no dot-to-dot collision push: circles can overlap, and each dot changes only its own motion. Centimeters are virtual simulation units, not a calibrated screen ruler.
Model note: a playful, simplified force model, not a scientific measurement device.Changes apply live. Nothing is uploaded.
