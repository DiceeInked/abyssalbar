# Abyssal

**A small place to exhale.** Abyssal is a self-contained, responsive sensory playground made with plain HTML, CSS, Canvas, and JavaScript.

## Explore

- **Five little worlds:** Tidepool, Aurora, Cloudroom, Stardust, and Rosewater. Each changes the accent palette and ambient glow.
- **Living light:** Tap or click the open page, or press the central orb, to send gentle ripples through the scene.
- **Surprise me:** Jump into a different world and let it scatter a few ripples for you.
- **A one-minute breathing guide:** A visual four-second inhale and six-second exhale rhythm. You can pause or reset it at any time.
- **Constellations:** Scatter a handful of small lights into the scene.
- **Optional ambient tones:** Synthesized in the browser and off by default. No sound starts until you turn it on.
- **Reduced motion:** Use the Motion control, or let the browser's reduced-motion preference take effect.
- **Responsive by design:** Layout adapts for phone, tablet, and desktop; interactive controls have accessible labels and visible keyboard focus.

## Run it

There is no build step, package install, framework, or API key. Open index.html in a browser, or publish the repository root with GitHub Pages.

To publish with GitHub Pages, open **Settings → Pages** and select the main branch with the root folder as the source, if Pages is not already configured.

## Privacy

The experience is entirely client-side. It does not include analytics, advertising, cookies, external fonts, external image requests, or data collection. Ambient audio is generated locally by the browser's Web Audio API and is opt-in.
